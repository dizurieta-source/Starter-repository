# Starter-repository

Incluye las skills `watch` y `video-a-skill` en `.claude/skills/`, para que cualquier sesión de Claude Code abierta con este repositorio pueda usarlas.

- `watch` usa el motor Gemini: necesita la variable `GEMINI_API_KEY` configurada en el entorno de la nube (nunca en este repositorio).
- La copia original de las skills vive en `dizurieta-source/claude-skills`; si cambian allá, hay que volver a copiarlas aquí.
